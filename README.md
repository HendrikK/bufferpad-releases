# BufferPad releases

Signed and notarized BufferPad disk images, and the update feed BufferPad checks.

- Downloads: [Releases](https://github.com/HendrikK/bufferpad-releases/releases)
- Update feed: `https://updates.bufferpad.app/appcast.xml` (served from this repository by GitHub Pages)

This repository is written by `tools/release/publish.sh` in the BufferPad repository. Don't edit `appcast.xml` by hand: every entry is signed.
